# Фотографии врачей

Чтобы заменить портрет без правок HTML, CSS или JavaScript, добавьте PNG с тем же базовым именем, что у существующего SVG:

- `babin-vyacheslav.png`
- `babina-irina.png`
- `kalinina-ekaterina.png`
- `zakroishchikova-inessa.png`
- `pavlichenko-svetlana.png`
- `sviridonova-marina.png`

Сайт автоматически проверяет наличие PNG и показывает его вместо резервного SVG. Удалять SVG не нужно.

## Рекомендации по подготовке

- формат: PNG;
- пропорции: строго 4:5, вертикальные;
- размер в пикселях может быть любым; для хорошей чёткости желательно не меньше 800 × 1000 px;
- лицо и верхняя часть корпуса должны находиться по центру;
- оставьте свободное поле над головой не менее 8% высоты;
- не размещайте важные детали у краёв;
- используйте одинаковый фон и масштаб для всей серии;
- рекомендуемый вес файла: до 1 МБ.

Если все фотографии подготовлены в пропорции 4:5, сайт показывает их в контейнерах с теми же пропорциями и не обрезает изображение из-за различий между квадратными и вертикальными карточками.
