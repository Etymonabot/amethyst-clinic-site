# Изображения для блога

Для каждой статьи можно использовать:

- главное изображение карточки и статьи;
- изображения внутри отдельных разделов;
- схемы и инфографику;
- подписи и указание источника в `<figcaption>`.

Рекомендуемые параметры главного изображения: горизонтальные пропорции 14:9 или 16:10, ширина от 1400 px. Для фотографий используйте WebP или PNG; для схем — SVG. Осмысленный `alt` обязателен для информативных изображений. Декоративным изображениям оставляйте пустой `alt=""`.
