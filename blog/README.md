# Медицинский блог «Аметиста»

## Как устроен блог

- `blog/index.html` — каталог и поиск по статьям;
- `blog/articles/` — отдельные SEO-страницы материалов;
- `js/blog-articles.js` — карточки и метаданные каталога;
- `js/search-index.js` — общий поиск по сайту;
- `images/blog/` — обложки, схемы и изображения внутри статей.

Каждая статья связывается с врачом через `authorKey`. На странице статьи имя автора ведёт в профиль врача, а на странице врача автоматически появляется блок «Статьи врача».

## Как добавить статью

1. Создайте HTML в `blog/articles/` с понятным адресом на латинице.
2. Добавьте уникальные `<title>` и `<meta name="description">`.
3. Используйте один `h1`, логичную иерархию `h2`/`h3` и оглавление со ссылками на `id` разделов.
4. Укажите автора, дату публикации и дату обновления.
5. Добавьте запись в `js/blog-articles.js` для каталога.
6. Добавьте запись в `js/search-index.js` для общего поиска.
7. Свяжите материал с врачом через `authorKey`.
8. Проведите медицинскую и редакторскую проверку перед публикацией.

## Изображения

Добавляйте изображения в `images/blog/`. Каждое информативное изображение должно иметь осмысленный `alt`; под изображением можно использовать `<figcaption>` с подписью и источником. Не вставляйте изображения только ради заполнения пространства.

## Важно для SEO-запуска

Сейчас сайт остаётся закрытым предпросмотром: страницы содержат `noindex`, а `robots.txt` запрещает обход. В таком состоянии поисковики не будут индексировать блог. Перед публичным запуском необходимо отдельной согласованной правкой:

1. убрать пароль или перенести защиту только на staging;
2. заменить `noindex` на разрешение индексации публичных страниц;
3. обновить `robots.txt`;
4. добавить абсолютные canonical URL после подключения домена;
5. сформировать `sitemap.xml`;
6. зарегистрировать сайт в Яндекс Вебмастере и Google Search Console.
