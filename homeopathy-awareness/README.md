# «Не магия» — эксплейнер о гомеопатии

Самостоятельный одностраничный просветительский сайт о том, почему гомеопатия не имеет доказанной эффективности и чем опасна подмена лечения.

## Публикация на GitHub Pages

Проект подготовлен к бесплатной публикации через GitHub Pages: workflow
`.github/workflows/deploy-homeopathy-pages.yml` загружает содержимое этой папки
как корень сайта. Поэтому адреса стилей и скриптов работают и на домене проекта
вида `https://<пользователь>.github.io/<репозиторий>/`.

1. Опубликуйте репозиторий на GitHub. На бесплатном тарифе репозиторий должен
   быть публичным, если ваш план не поддерживает Pages для приватных репозиториев.
2. Откройте **Settings → Pages** и в разделе **Build and deployment** выберите
   источник **GitHub Actions**.
3. Откройте вкладку **Actions**, выберите workflow
   **Deploy homeopathy awareness site to Pages** и нажмите **Run workflow**.
4. После первого деплоя адрес сайта появится в **Settings → Pages** и в сводке
   выполненного workflow.

В дальнейшем публикация запускается автоматически после изменений в папке
`homeopathy-awareness/`. Ограничивать публикацию конкретной веткой не требуется,
поэтому workflow продолжит работать, даже если основная ветка будет переименована.

Файл `.nojekyll` отключает обработку Jekyll: GitHub Pages отдаёт HTML, CSS и
JavaScript без преобразований.

## Локальный запуск

Откройте `index.html` напрямую или запустите локальный сервер из этой папки:

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173/`.
